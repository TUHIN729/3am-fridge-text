The one line a smart fridge texts its owner at 3am. It overheard its owner tell a date it "came with the apartment" — and it has receipts: it has outlasted the owner's last three relationships combined.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
